タスクバー

Windows 11 のタスクバーを、中央に浮かぶガラスのピル型に変えます。アプリアイコンを重ねてドラッグするとフォルダーにまとめられます。

PillTaskbar のソース

モニターごとの Alt+Tab

モニターが複数あるとき、カーソルのあるモニターに Alt+Tab を出し、そのモニターのウィンドウだけを表示します。

AltTabPerMonitor のソース

メモリ整理

タスクバーの時計の横にメモリ使用量が出ます。クリックするとメモリを空けて、プログラムを終了できます。

MemoryClean のソース

モニターの明るさ調整

時計の横でモニターごとに明るさを合わせます。スライダーひとつで全部のモニターが変わり、ホイールでも変えられます。

MonitorBrightness のソース

コーヒー

時計の横のコーヒーカップをオンにすると、PC と画面がスリープしません。オフにするまで、または決めた時間だけ続きます。

KeepAwake のソース

設定 › アドオン からボタンひとつでダウンロードでき、内蔵のハッシュ値と一致するときだけインストールされます。

ダウンロードの前に。インストールとプライバシーに関する 4 つの案内

SmartScreen の警告+

まだコード署名を行っていないため、「Windows によって PC が保護されました」と表示されることがあります。詳細情報 › 実行 を押してください。

インストール先+

現在のアカウントの %LOCALAPPDATA%\BloomLauncher にインストールされ、スタートメニューにショートカットが作られます。.NET 10 Desktop Runtime が入っていないときだけ一緒にインストールされ、権限の承認を求めます。

AI に送られるもの+

自分で送った質問や添付ファイル、Bloom Lens で選んだ画面、翻訳する文章、PC 操作ツールの結果だけが送られます。

API キーは Windows が暗号化してこの PC 内にのみ保管し、該当サービスへリクエストを送るときだけ使われます。

更新とアンインストール+

起動後に一度だけ新しいバージョンを確認し、次回の起動時に適用します。設定 › バージョン情報 から自動確認をオフにできます。

設定 › データ › Bloom をアンインストール から、チャットや設定も一緒に消すかどうかを選べます。Windows の 設定 › アプリ から削除した場合はデータが残ります。
