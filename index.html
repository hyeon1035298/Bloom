  4. 4

    묻기 선택 Tab

    Claude Code나 Codex에 로그인돼 있거나 API 키를 넣었다면, 같은 줄에서 Tab으로 묻습니다.

받기 전에.설치와 개인정보에 관한 네 가지.

SmartScreen 경고+

아직 코드 서명이 없어서 “Windows의 PC 보호”가 뜰 수 있습니다. 추가 정보 › 실행을 누르세요.

설치되는 곳+

현재 Windows 계정의 %LOCALAPPDATA%\BloomLauncher에 설치되고 시작 메뉴 바로 가기가 생깁니다. .NET 10 Desktop Runtime이 없으면 자동으로 함께 설치하며, 이때 Windows가 권한 승인을 묻습니다.

AI에게 가는 것+

직접 보낸 질문과 첨부 파일, Bloom Lens로 고른 화면, 번역할 글, PC 작업 도구의 결과만 전달됩니다.

API 키는 Windows가 암호화해 이 PC에만 저장하고, 각 키는 해당 서비스로만 보냅니다.

업데이트와 제거+

실행 후 한 번 최신 릴리스를 확인하고, 새 버전은 다음 실행 때 적용합니다. 설정 › 정보에서 자동 확인을 끌 수 있습니다.

제거는 설정 › 데이터 › Bloom 삭제에서 하며, 대화와 설정을 함께 지울지 고를 수 있습니다. Windows 설정 › 앱에서 제거하면 데이터는 남습니다.

키 하나면됩니다.
